# Full Stack Open

[Full Stack Open](https://fullstackopen.com/) course by the University of Helsinki.

I completed the core course for **7 ECTS credits with grade 5/5** and continue
studying additional parts of the course. I am currently working on **Part 13:

## Featured Project: Bloglist

Bloglist is a full stack web application that has been progressively developed
through several parts of the Full Stack Open course.

The application includes:

- user authentication with JWT
- blog creation and management
- liking blogs
- user-specific permissions
- REST API communication between frontend and backend
- backend and frontend testing
- end-to-end testing with Playwright

The original backend was implemented with **MongoDB and Mongoose**.

I am currently migrating the backend to **PostgreSQL** using **Sequelize**.
